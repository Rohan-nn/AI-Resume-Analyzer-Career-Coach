# AI Resume Analyzer & Career Coach

AI-powered Resume Analyzer built using Streamlit and Google Gemini AI.

## Features

* ATS Score Analysis
* Resume Strength Analysis
* Skill Gap Detection
* Job Description Matching
* AI Resume Review
* AI Resume Summary
* AI Interview Questions
* Career Feedback
* Career Roadmap Generation
* Cover Letter Generator
* LinkedIn Summary Generator
* PDF Report Download

## Tech Stack

* Python
* Streamlit
* Gemini AI
* Plotly
* Pandas
* PDFPlumber
* ReportLab

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Project Workflow

1. Upload Resume
2. Paste Job Description
3. Analyze ATS Score
4. Generate AI Feedback
5. Create Cover Letters
6. Download PDF Report
